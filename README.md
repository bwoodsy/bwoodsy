## Featured Projects

### [Business Management System](https://github.com/bwoodsy/Business-Management-System)
Full-stack application built for a local phone repair shop — handling inventory, customers, and service workflows. Live in production, serving 500+ monthly requests. Reduced query response time by 30% through SQL Server profiling and indexing. Implemented JWT authentication with role-based access control from scratch.

**Tech:** C#/.NET · Angular · TypeScript · SQL Server

### [SecureCode-AI](https://github.com/bwoodsy/code-security-scanner)
Static analysis tool that scans Python codebases for OWASP Top 10 vulnerabilities. Used on a freelance client's codebase pre-deployment — identified 12 security issues. Improved detection accuracy from 18% to 54% through AST pattern matching refinements.

**Tech:** Python · AST Parsing · OpenAI API

### [Event Management System](https://github.com/bwoodsy/event-management-system)
Android application for event organizers with real-time updates, push notifications, and waitlist management. Built with a 6-person team — wrote 180+ unit and integration tests achieving 80% coverage, caught a race condition bug in code review before release.

**Tech:** Java · Android · Firebase · JUnit
